SECTION 1: DOCUMENT OVERVIEW 
1.1 Purpose 
This SRS defines the complete, machine-readable, AI-executable specification for the Minimum Viable Product (MVP) 
of "MPLADS Sentinel" — an AI-powered monitoring and analytics platform designed to detect anomalies, fraud, and 
inefficiencies in the Members of Parliament Local Area Development Scheme (MPLADS) implementation. Every 
requirement in this document is written as an unambiguous, testable instruction that an AI agentic development 
system can interpret, implement, and verify without human clarification. 
1.2 Scope 
1.2.1 In-Scope (MVP Boundary) 
YAML 
MVP_SCOPE: 
  DATA_INGESTION: 
    - Ingest MPLADS data from public dashboard CSV/API exports 
    - Parse and normalize sanction, expenditure, work progress, and payment records 
    - Store in structured relational + vector database schema 
 
  ANOMALY_DETECTION: 
    - Statistical anomaly detection on cost estimates vs actual expenditure 
    - Duplicate work detection using NLP similarity on work descriptions 
    - Delayed project identification based on timeline deviation thresholds 
    - Cost overrun flagging using z-score and IQR methods 
    - Fund utilization rate analysis per constituency per fiscal year 
 
===== PAGE 2 =====
  FRAUD_RISK_SCORING: 
    - Composite risk score per work item (0-100 scale) 
    - Rule-based + ML-based hybrid scoring model 
    - Classification of risk into LOW / MEDIUM / HIGH / CRITICAL tiers 
 
  DASHBOARD: 
    - Web-based responsive dashboard with role-based views 
    - National overview heatmap 
    - Constituency-level drill-down 
    - Alert feed with severity indicators 
    - Trend analysis charts (time-series) 
 
  ALERTING: 
    - Automated alert generation on anomaly detection 
    - Alert categorization: COST_OVERRUN | DUPLICATE_WORK | DELAYED_PROJECT | FUND_MISUTILIZATION | 
PATTERN_ANOMALY 
    - Alert log with audit trail 
 
  REPORTING: 
    - Exportable PDF/CSV reports per constituency 
    - Summary analytics for ministry-level review 
1.2.2 Out-of-Scope (Post-MVP) 
YAML 
OUT_OF_SCOPE: 
  - Real-time API integration with MPLADS live production database 
  - Mobile native applications (iOS/Android) 
  - Multi-language NLP (MVP: English only) 
  - Automated corrective action workflows 
  - Integration with PFMS (Public Financial Management System) live feeds 
  - Biometric or identity verification modules 
  - SMS/WhatsApp notification delivery 
  - Predictive budget forecasting models (future phase)
